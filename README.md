# PHP The Right Way
This version allows to learn PHP from basics to intermediate 

## Install PHP
What we recommend is to install XAMPP, which is a free and open-source cross-platform web server solution stack package developed by Apache Friends, consisting mainly of the Apache HTTP Server, MariaDB database, and interpreters for scripts written in the PHP and Perl programming languages.

Another option is to install PHP directly on your machine, which can be done by following the instructions on the official PHP website: https://www.php.net/manual/en/install.php

In next sections, we will configure a docker container to run our PHP code, but for now, you can use XAMPP or direct installation to start learning PHP.

## Selecting a Text Editor
To write PHP code, you can use any text editor. Some popular options include:
- Visual Studio Code (VS Code)
- Claude Text Editor
- Antigravity
- PHPStorm (paid)
